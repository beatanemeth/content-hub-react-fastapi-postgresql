## Typography

- **Google Fonts:** H1-6: Raleway; paragraph: Poppins.
- **Google Fonts weights to load:** Raleway 600 and 700; Poppins 400, 400 italic and 500.

| Element                           | Family  | Size (Tailwind)    | Weight | Other                                         |
| --------------------------------- | ------- | ------------------ | ------ | --------------------------------------------- |
| **Logo** ("Bloom & Burr")         | Raleway | 30px (`text-3xl`)  | 700    |                                               |
| **`h1`** (page title, post title) | Raleway | 72px (`text-7xl`)  | 700    | line height 1.2                               |
| **`h2`** (post-card title)        | Raleway | 36px (`text-4xl`)  | 600    | line height 1.3                               |
| **Body text, inputs, nav links**  | Poppins | 20px (`text-xl`)   | 400    | `leading-relaxed`                             |
| **Labels**                        | Poppins | 20px (`text-xl`)   | 500    |                                               |
| **Buttons**                       | Poppins | 20px (`text-xl`)   | 500    | uppercase                                     |
| **Meta line**                     | Poppins | 14px (`text-sm`)   | 400    | uppercase, `tracking-wide`                    |
| **Categories**                    | Poppins | 14px (`text-sm`)   | 400    | `tracking-wide`; labels keep their PascalCase |
| **Tags**                          | Poppins | 14px (`text-sm`)   | 400    | italic                                        |
| **Footer**                        | Poppins | 16px (`text-base`) | 400    |                                               |
