# Records of the real GCP run

> **Real GCP:** the output of the [runbook](../runbook.md) commands, saved with `( set -x; <command> ) 2>&1 | tee <file>`, and the Console screenshots of the same run. The runbook also holds the notes and findings of this run.

- **Order:** the prefix is the runbook step (`s2-6` = part 2, step 6).
- **Commands:** ready for the next run, from the repository root, in the first terminal. They write the records under the names below into the git-ignored `.build/real-run/`. Where the run differed, the table gives the corrected command and says what happened.
- **Placeholders:** `<project-id>`, `<project-number>`, `<email>` and `<service-url>` replace the real values.
- **Screenshots:** the browser's tab strip is cropped off; grey boxes cover the private values. On the app pages, the address bar stays and only the project number in it is covered. On the Console pages, everything after `console.cloud.google.com` is covered.
- **Trimmed:** `s2-3-plan.txt`, `s2-6-apply.txt` and `s5-1-destroy.txt` keep the resource list, the progress lines and the totals; the resource attributes are removed. Each file says so in its first line. `s2-5-push.txt` has no `Waiting` lines.
- **Never recorded:** step 3.2, because it reads the database password.
